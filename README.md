# 24 DAYS — MVP Telegram Mini App

Пошаговая инструкция: что делать и куда нажимать, от распаковки архива до запуска приложения внутри Telegram.

---

## Часть 1. Установка на компьютер

### Шаг 1 — Распаковать архив
Распакуй `24days-mvp.zip` в любую папку, например `C:\Projects\24days-mvp` или `~/Projects/24days-mvp`.

### Шаг 2 — Открыть в Cursor
1. Открой **Cursor**.
2. Нажми **File → Open Folder** (в левом верхнем меню).
3. Выбери папку `24days-mvp`, которую только что распаковал.
4. В левой панели (Explorer) появится дерево файлов проекта.

### Шаг 3 — Открыть встроенный терминал
1. В верхнем меню Cursor нажми **Terminal → New Terminal**.
2. Внизу окна откроется чёрная панель терминала — сюда будем вводить команды.

### Шаг 4 — Установить зависимости
В терминале введи и нажми Enter:
```
npm install
```
Подожди, пока команда закончится (появится новая строка-приглашение). Это скачает React, Vite и другие библиотеки в папку `node_modules`.

### Шаг 5 — Запустить проект локально
В терминале введи:
```
npm run dev
```
После запуска в терминале появится строка вида:
```
➜  Local:   http://localhost:5173/
```
Зажми **Ctrl** (на Mac — **Cmd**) и кликни по этой ссылке — откроется браузер с приложением. Пока это просто веб-страница, не Telegram Mini App — так проверяем, что всё работает.

Если видишь экран «24 DAYS» с Днём 1 и кнопкой «Отметить день выполненным» — всё работает правильно.

## Часть 2. Создание бота в Telegram

### Шаг 1 — Открыть BotFather
1. Открой Telegram.
2. В поиске введи `@BotFather` и открой чат с ним (у него синяя галочка подтверждённого аккаунта).

### Шаг 2 — Создать нового бота
1. Отправь ему команду `/newbot`.
2. Он спросит имя бота — введи любое, например `24 Days Productivity`.
3. Он спросит username бота — он должен заканчиваться на `bot`, например `days24_yourname_bot`.
4. BotFather пришлёт сообщение с **токеном** вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
5. **Скопируй этот токен и сохрани в заметке** — он понадобится позже для бота-напоминалки, никому его не показывай.

### Шаг 3 — Включить Mini App для бота
1. В том же чате с BotFather отправь `/mybots`.
2. Выбери своего бота из списка.
3. Нажми кнопку **Bot Settings**.
4. Нажми **Menu Button**.
5. Нажми **Configure Menu Button**.
6. Введи текст кнопки, например `Открыть 24 DAYS`.
7. BotFather попросит ссылку — это будет ссылка на твой задеплоенный сайт (получим её в Части 3). Пока можно пропустить этот шаг и вернуться к нему позже.

## Часть 3. Деплой на Vercel (чтобы Telegram мог открыть сайт)

Telegram Mini App должен открываться по **https**-ссылке, поэтому localhost не подходит — нужен реальный домен.

### Шаг 1 — Создать аккаунт на Vercel
1. Зайди на **vercel.com**.
2. Нажми **Sign Up**.
3. Выбери **Continue with GitHub** (проще всего, понадобится аккаунт GitHub).

### Шаг 2 — Загрузить проект на GitHub
1. Зайди на **github.com**, нажми **+** в правом верхнем углу → **New repository**.
2. Введи имя репозитория, например `24days-mvp`, нажми **Create repository**.
3. В терминале Cursor (внутри папки проекта) выполни по очереди:
```
git init
git add .
git commit -m "первый коммит"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЮЗЕРНЕЙМ/24days-mvp.git
git push -u origin main
```
(замени `ТВОЙ_ЮЗЕРНЕЙМ` на свой логин GitHub)

### Шаг 3 — Подключить проект к Vercel
1. В Vercel нажми **Add New… → Project**.
2. Найди репозиторий `24days-mvp` в списке и нажми **Import**.
3. Vercel сам определит, что это Vite-проект. Ничего не меняй.
4. Нажми **Deploy**.
5. Через минуту появится страница с надписью **Congratulations!** и ссылкой вида `https://24days-mvp.vercel.app`.
6. **Скопируй эту ссылку** — это и есть адрес твоего Mini App.

### Шаг 4 — Привязать ссылку к боту
1. Вернись в чат с **BotFather**.
2. Повтори шаги из «Часть 2, Шаг 3»: `/mybots` → выбери бота → **Bot Settings** → **Menu Button** → **Configure Menu Button**.
3. На этот раз вставь ссылку с Vercel (`https://24days-mvp.vercel.app`).

### Шаг 5 — Проверить в Telegram
1. Открой чат со своим ботом в Telegram (найди по username, который задавал в BotFather).
2. Внизу экрана рядом с полем ввода сообщения появится кнопка меню с текстом, который ты задал (например «Открыть 24 DAYS»).
3. Нажми на неё — приложение откроется прямо внутри Telegram на весь экран.
4. Нажми «Отметить день выполненным» — обнови приложение (смахни его вниз, чтобы закрыть, и открой заново через ту же кнопку) — прогресс должен сохраниться. Это значит, что CloudStorage работает.

## Часть 4. Бэкенд: тред дня и напоминания бота

Serverless-функции лежат в `api/` и деплоятся Vercel вместе с сайтом. Данные — в Supabase
(таблицы `days24_users`, `days24_posts`, `days24_reactions`, функция `days24_thread`), доступ к ним
только с сервера через service-role ключ.

### Шаг 1 — Переменные окружения в Vercel
Vercel → проект → **Settings → Environment Variables** (см. `.env.example`):

| Переменная | Откуда |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | любая случайная строка, например `openssl rand -hex 32` |
| `CRON_SECRET` | ещё одна случайная строка — Vercel сам подставит её в запросы cron |
| `SUPABASE_URL` | Supabase → Project Settings → API → Project URL |
| `SUPABASE_SERVICE_ROLE_KEY` | там же → `service_role` (секретный, не anon) |
| `APP_URL` | адрес сайта, `https://24days-mvp.vercel.app` |

После добавления переменных нужен новый деплой (Deployments → Redeploy).

### Шаг 2 — Вебхук бота
Один раз выполнить в терминале, подставив токен и секрет:
```
curl "https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://24days-mvp.vercel.app/api/telegram&secret_token=<TELEGRAM_WEBHOOK_SECRET>"
```
Команды бота: `/start` — включить напоминания, `/stop` — выключить. В BotFather можно
зарегистрировать их через `/setcommands`.

### Шаг 3 — Напоминания
`vercel.json` содержит cron `0 4 * * *` (04:00 UTC = 10:00 по Бишкеку). На Hobby-тарифе cron
запускается раз в сутки и может сдвигаться в пределах часа. Бот шлёт «День N: …» тем, кто
включил напоминания и ещё не отметил сегодняшний день.

### Что делают эндпоинты
- `POST /api/progress` — приложение сообщает текущий день, фокус и дату последней отметки
- `GET/POST/DELETE /api/thread?day=N` — лента заметок дня; поделиться своей; убрать свою
- `POST /api/react` — реакция «помогло» (повторно — снять)
- `POST /api/telegram` — вебхук бота
- `GET /api/remind` — cron-рассылка (только с `Authorization: Bearer CRON_SECRET`)

Все запросы из приложения подписаны `initData` Telegram (заголовок `Authorization: tma …`),
подпись проверяется по HMAC с токеном бота. Скрыть неудачный пост: `hidden = true` в
таблице `days24_posts`.

## Что дальше (следующие версии)

Этот MVP закрывает только 6 базовых функций: вход через Telegram, дни 1–24, задачи дня, отметка «выполнено», прогресс-бар, сохранение между сессиями. Дальше по порядку:

- **V0.2** — экран «Мой проект» с полями цели и KPI продукта (сейчас `product_action` просто текст внутри карточки дня)
- **V0.3** — бот с ежедневными напоминаниями через webhook (нужен отдельный маленький сервер — можно на Vercel Functions)
- **V0.4** — AI-коуч (нужен backend, который вызывает Anthropic API с контекстом дня и статуса продукта)
- **V0.5** — подписка/оплата через Telegram Payments

Не делай их все сразу — сначала дай 5 людям попробовать текущую версию и посмотри, доходят ли они хотя бы до Дня 6.

## Структура проекта

```
24days-mvp/
├── index.html              — точка входа, подключает Telegram SDK
├── src/
│   ├── main.tsx             — монтирование React-приложения
│   ├── App.tsx               — главный экран, логика навигации по дням
│   ├── index.css             — все стили (тёмная тема, жёлтый акцент)
│   ├── telegram.d.ts         — типы для window.Telegram
│   ├── focus.ts              — три фокуса (продукт / учёба / здоровье) и их подписи
│   ├── courses.ts            — список курсов и подстановка {привычка}
│   ├── data/
│   │   ├── days.json         — курс «Продуктивный год»: 24 дня, actions под каждый фокус, metric
│   │   ├── habits.json       — курс «Атомные привычки»: action с {привычка} и примеры по фокусу
│   │   └── gtd.json          — курс «Дела в порядке» (GTD): action и примеры по фокусу
│   ├── components/
│   │   ├── DayCard.tsx        — карточка одного дня
│   │   ├── BlockSummary.tsx   — сводка замеров на обзорных днях (6, 12, 18, 24)
│   │   ├── CoursePicker.tsx   — выбор курса
│   │   ├── FocusPicker.tsx    — выбор фокуса
│   │   └── HabitSetup.tsx     — ввод своей привычки (курс «Атомные привычки»)
│   └── hooks/
│       └── useCloudStorage.ts — сохранение/чтение прогресса через Telegram CloudStorage
├── package.json
├── vite.config.ts
└── tsconfig.json
```

Если захочешь поменять текст задач по дням — редактируется только `src/data/days.json`, `src/data/habits.json` или `src/data/gtd.json`, код трогать не нужно.
